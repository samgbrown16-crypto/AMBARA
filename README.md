# AMBARA Rwanda

AMBARA is an open fashion marketplace platform for Rwanda, connecting buyers and sellers directly via WhatsApp and Mobile Money.

## How to Run Locally
1. Extract this ZIP folder.
2. Open `index.html` in any modern web browser or host it on Vercel, Netlify, or GitHub Pages. Hero and product photos are stored in the `images/` folder.
3. To change a listing photo, add the image to the project and set that listing's `img` property in `index.html` to its relative path.
